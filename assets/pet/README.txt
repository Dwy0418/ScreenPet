把你自己的形象图放到这个文件夹里，程序会自动用它替换内置的占位形象。

## 基础帧（必须）

命名规则（按文件名**末尾的数字**排序播放，建议补零成 idle_00.png … idle_11.png）：

    idle_0.png idle_1.png idle_2.png ...    待机帧（呼吸/眨眼可以画进帧里）
    talk_0.png talk_1.png talk_2.png ...    说话帧（没有的话就用待机帧代替）

## 情绪帧（可选，配合表情状态机）

模型会给每句话打一个情绪标签，如果你为某种情绪画了专门的帧，就会自动切过去：

    happy_*.png       开心
    speechless_*.png  无语
    excited_*.png     激动
    curious_*.png     好奇
    smirk_*.png       吐槽

没有对应情绪的帧时，会退回 talk / idle，并自动叠加上"歪头 + 身体配色微调"
的动效（幅度由情绪决定），所以静态图也不会显得死板。

## 串门动作帧（可选）

两只桌宠串门时会一起做动作（见 `pet/play.py`），每个动作对应一套帧：

    highfive_*.png    击掌
    bump_*.png        撞拳
    hug_*.png         抱一下
    sway_*.png        一起晃
    peekaboo_*.png    躲猫猫
    pat_*.png         拍一拍
    wink_*.png        抛媚眼

命名、加载规则跟 `idle_*` / 情绪帧完全一样（同样建议补零成 `highfive_00.png …`）。
有帧就**按动作进度播那套帧**；哪套动作没放帧也不冷场——它会**蹦一下**（`sprite.act_lift`）
+ 说那句配词，少放几套绝不会崩。
内置形象这 7 套是 `tools/make_pet.py` 一起生成的（各 12 帧，抖法写在 `pet/play.py` 的动作表里，
生成时从同一张表取），想换成手画的直接覆盖同名文件即可。

## 日常状态帧 / 界面互动动作（可选）

上面那 7 套是「两只凑一起」的。它**自己待着**的样子、以及**你在本机跟它互动**时的小反应，
是另一批帧（见 `pet/states.py`），一共 18 条：

    idle_*.png      待机       talk_*.png     说话      ← 就是上面的基础帧，没重复做
    walk_*.png      走路       sit_*.png      坐下      sleep_*.png    睡觉
    stretch_*.png   伸个懒腰   think_*.png    想事情    look_*.png     张望
    nod_*.png       点点头     shake_*.png    摇摇头    wave_*.png     挥挥手
    jump_*.png      蹦一下     cheer_*.png    欢呼
    greet_*.png     打招呼     poke_*.png     被戳      confused_*.png 疑惑
    eat_*.png       吃饭       slack_*.png    摸鱼

名字、加载规则跟前面几批一样（同一张帧表，见 `sprite.frames_acts`），两种播法：

* **一直循环**（走路 / 坐下 / 睡觉 / 想事情 / 张望）：界面按「它现在什么情况」切过去——
  暂停 = 睡觉、麦克风开着 = 张望、等模型回话 = 想事情、正被你拖着 = 走路；
  转完一轮多久由 `pet/states.py` 里那条状态的 `seconds` 定。
* **播一遍就停**（打招呼 / 被戳 / 疑惑 / 吃饭 / 摸鱼 / 挥手 / 点头 / 摇头 / 蹦一下 / 欢呼 /
  伸懒腰）：触发口子有几个，都写在 `pet/states.py` 的表里——
  - 你把**鼠标停在它身上**一会儿 → 挥挥手（`REACTIONS.hover`）；
  - 你**单击**它一下 → 从 `CLICK_ACTIONS` 那张随机池里**随机演一个**
    （挥手 / 打招呼 / 欢呼 / 点点头 / 摇摇头 / 疑惑 / 被戳惊跳 / 蹦一个 / 喂一口 / 摸鱼 /
    伸个懒腰），同一个动作不连着演两次，挑哪个见 `window.PetWindow._on_click`
    （以前这些动作是右键菜单「逗它一下」那一节一项项点的，现在菜单里不再单列）；
  - 你**双击**它一下 → 被戳，同时还顺手暂停 / 继续看（`REACTIONS.double`）；
  - 你把它**拖起来又放下** → 蹦一下（`REACTIONS.drop`）；
  - **抓到的画面是什么情绪**就带什么动作：开心 / 激动 → 欢呼、惊讶 → 被戳般惊跳、
    好奇 → 疑惑、无语 / 生气 → 摇头、难过 → 坐下、吐槽 → 摸鱼（`MOOD_ACTIONS`，
    情绪本身见 `pet/mood.py`）。
  - `nod_` / `shake_` 那套点头、摇头另有名字 `REACTIONS.agree` / `.deny`，
    留给对话 / 好友那边应答用。

哪条没放帧都不崩：循环的状态会老实退回待机 / 说话，一次性的互动退回「蹦一下」（`sprite.act_lift`）。
内置形象这些（待机 / 说话不用重做）也是 `tools/make_pet.py` 一起生成的，各 12 帧。

**动作是"逐拍排"出来的**，分两层：

1. **整张图**一起摆：`pet/states.py` 里每条状态可以写 `keys`（手写关键帧）——
   `dx/dy` 位移、`scale` 缩放、`squash` 纵向压扁、`tilt` 旋转，`make_pet.py` 再插值采成 12 帧；
   没写 `keys` 的就用原来的正弦抖法（呼吸那种）。走路左右脚交替就是这么来的。
2. **逐部件**摆（`rig_keys`，头绕脖子、手臂绕肩）：这才是"真的在点头 / 在挥手"。
   每拍给整体那套参数 + 两个部件：`head` 的 `dy/dx` 位移和 `angle`（头往下沉 = 点头、
   左右转 = 摇头、转个角度 = 歪头）、`arm` 的 `angle`（往外侧抬起 = 挥手 / 欢呼）。
   生成时 `tools/make_pet.py` 把形象拆成**躯干 / 头 / 手臂**三块各自转（挖走部件留下的
   洞按旁边的颜色补上），静止姿势和原图逐像素一致。所以点头是头在点、身子不动，
   挥手是手绕肩抬起来。部件位置在 `make_pet.py` 顶上的 `RIG_*`（画布比例），照当前这个
   形象量的；换一张完全不同的图、切歪了就加 `--no-rig`（动作退回第一种，不崩）。

所以被戳是缩团→惊跳→落地、吃饭是低头去够一口→鼓腮嚼→拍肚子，各是各的动作。
有些帧上还画了个小提示符号（疑惑的 `?`、被戳的 `!`、打招呼的星星、生气的怒气、
难过的汗滴）——只是让动作更好读，一个字都不上界面。

要求：

* PNG 透明底，正方形最好，边长 256px 以上（显示尺寸由 config.json 的 ui.pet_size 决定）。
* 帧数不限，1 张也能用（那样就是静静待着）。一整套帧转完一圈的时长由 config.json 的
  `ui.anim_period` 决定（默认 30 秒一轮，慢到看不出在动），情绪会让它按比例加快/放慢。
* **不用自己留白**：形象是画在圆形窗口里的，程序装帧时会自动裁掉透明边、再按
  「外接矩形的角刚好落在圆上」缩放居中，所以画满整张画布也不会被圆切成直边
  （以前就是这里翻车：脚和身体两侧被遮罩切掉）。想让形象更大/更小，
  调 `config.json` 里的 `ui.pet_size`（窗口和形象一起变大变小）。

放好之后重启程序即可。想换回内置的矢量形象，把这里清空就行。
预览效果：`python tools/render_preview.py preview.png`

## 眼睛跟着鼠标转 / 食指轻敲下巴（自动的）

`tools/make_pet.py` 生成帧的时候会顺手把两样东西抠出来，在本目录多写两组文件：

    eye_layer.png    眼珠那一层（透明底，和帧画布对齐）
    eye_layer.json   两只眼珠的位置/半径 + 每帧的身体变换矩阵
    hand_layer.png   搭在下巴上那根食指的一层
    hand_layer.json  敲的幅度/周期 + 每帧的身体变换矩阵

渲染器读到它们就会「先画身体那一帧，再把部件层按同一个身体变换叠回去，最后额外动一点」：
眼珠按鼠标方向转；食指**以指根为锚点往上抬一点**——指根那行不动、只有指尖抬起来，
所以手和手指之间不会裂开缝（早先是整块往上挪，露出来的补色看着就是手在自己伸缩）。
**这些文件是自动生成的，别手改**；没找到对应部件就不会有这些文件，形象照常用，只是少一个动作。

* 不想要：`python tools\make_pet.py 你的图.png --no-eyes` / `--no-hand`
* 找得不准：跑完看 `assets/source/eye_preview.png`、`hand_preview.png`（左=原图+标记框，
  中=抠出来的那一层，右=抹掉之后）。框没套准就手动指（256×256 画布像素坐标）：
  `--eyes 左x,左y,左r,右x,右y,右r` / `--hand-box 左,上,右,下`
* 相关配置：`ui.eye_tracking`（默认 true）、`ui.eye_follow_px`（默认 320，越小越灵敏）、
  `ui.hand_tap`（默认 true）；敲的幅度/快慢在生成时用 `--tap-lift` / `--tap-period` 定
  （一个周期里轻敲两下，其余时间贴着下巴）。
* 眼珠只动眼珠、不动眼皮，所以不会眨眼；食指只往上抬、不会往下戳。
* 手指那一层的框留白越小越好：跟着动的是框里**一整块**，留白大了抬起来就是一片手套。

## 现在这里装的是哪一套

当前这套帧是那张 3D 小人（源图 `assets/source/pet_new.png`，2048×2048，米色背景）：
`tools/make_pet.py` 抠掉背景、找出眼珠和搭在下巴上的食指，生成了整套帧（待机 / 说话 / 情绪
7 套 + 串门动作 7 套 + 日常状态 11 套，各 12 帧）+ 两个部件层（`eye_layer.*` / `hand_layer.*`）。几条退路：

    python tools\make_pet.py assets\source\pet_new.png               # 原样重做一遍
    python tools\make_pet.py assets\source\pet_new.png --no-hand     # 只要眼珠跟鼠标，不要敲下巴
    python tools\make_pet.py assets\source\pet_src.png               # 退回黄脸黄豆（换自拍 / 换裁法见 paste_face）
    python tools\make_pet.py --clear                                 # 退回内置矢量形象

这张图的背景是**暖米色**，而人物身上有白手套——两者灰度差只有 3，所以抠图靠的是
`--chroma 0.55` 那道彩度闸（背景彩度 34、手套只有 10）。换别的图如果白衣服被啃，
就把它调大一点。

背景上还压着一团**柔和的地面投影**（色相和背景一模一样、只是整体暗一档，实测是背景的
0.73~0.86 倍），彩度闸和色差容差都认不出它。它是靠 `--shade 0.5` 单独一条判定抠掉的
（判据是「逐通道除以背景色之后三个比值几乎相等」——皮肤差 0.19~0.34、白手套差 0.17，
只有背景自己的阴影差 0.015~0.042）。不清掉的话，深色桌面上脚下就是一块灰斑。
换图后如果脚下还留灰影：调大 `--shade`（保守）或调小（更狠），`--shade 0` 关掉。

抠完之后人物身上还会剩几条**1~4 像素宽的透明缝**（耳缝、下巴缝——背景从那儿渗进去了），
256 的画布上这种缝画不出来，缩放后就成了耳后那两道虚线脏边。`--heal 4` 会把「左右都被
实心像素夹住、自己又细又透明」的缝用两侧颜色补上；不想要就 `--heal 0`。

另外**两腿之间那道缝**（背景被上下的裤子和鞋子围成一个小口袋）从画布边缘灌不进去，
靠 `--strict 12` 单独扫掉——那是比主容差（26）严格得多的门槛，只有几乎和背景一模一样的
像素才算数；腿是黄的、离背景很远，所以不会被误伤。还留着就调大（16），啃到人物就调小（8）。

**这一版相对上一版改了哪儿**（都是"看起来像没抠干净"的毛病）：
脚下一团灰斑（地面投影）、耳后两道虚线脏边（1~4 像素透明缝）、两腿之间一条亮条（封闭的背景）。
