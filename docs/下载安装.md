# 下载安装（给玩家）

这份是给**用**的人看的：怎么把它弄到电脑上、第一次怎么配、出问题去哪儿看。
想改代码或自己打包，看 `docs/打包发布.md`。

## 一、下载

到项目的 **Releases** 页面，挑最新的那一版，下载：

| 文件 | 说明 |
| --- | --- |
| `ScreenPet-<版本>.zip` | **绿色版**（推荐）：解压就能用，不留痕 |
| `ScreenPet-Setup-<版本>.exe` | 安装包：有开始菜单和卸载项（如果这一版提供了的话） |

Windows 可能弹「已保护你的电脑」（SmartScreen）——因为 exe 没买代码签名证书。
点「更多信息」→「仍要运行」即可。介意的话可以自己从源码打包（见另一份文档）。

## 二、装 & 跑

**绿色版**：把 zip 解压到**任意**文件夹（桌面、D 盘、U 盘都行）→ 双击 `ScreenPet.exe`。
屏幕边上就冒出一只宠物，托盘里有它的图标。

**安装包**：双击一路下一步。默认装在当前用户目录，不需要管理员。

跑起来之后：

- 桌面上会多一只挂件：**鼠标左键点它一下**，它就从动作池里随机演一个（挥手 / 打招呼 / 欢呼 /
  点头 / 摇头 / 疑惑 / 被戳 / 蹦一下 / 吃饭 / 摸鱼 / 伸懒腰）；想打字聊天走右键
  →「跟我说说话」→「打字跟我唠…」；
  按住左键拖动可以挪位置，双击让它先歇会儿（不看了 / 继续）；
- 托盘图标点一下 = 收起来 / 放出来（托盘右键菜单里**只有「显示挂件」**这一项）；
- 右键挂件 = 全部菜单（划观看范围、只盯某个程序、打开配置、记忆……）；
  鼠标停在托盘图标上，它说两句人话——**「我懂你：…」**（它摸清的你的口味）
  和**「现在：…」**（这会儿在看什么），不是后台计数。

## 三、第一次配置（填 API Key）

默认是**离线演示模式**（`provider: "mock"`）：形象、动画、热键、托盘、打字聊天都能试，
只是它说的话来自内置样本、不看你的屏幕。要它真的"看画面、说人话"，得接一个模型：

1. 右键挂件 →「打开配置文件」（或者手动打开 `%APPDATA%\ScreenPet\config.json`）；
2. 改三个字段（以智谱为例）：

   ```json
   {
     "provider": "zhipu",
     "base_url": "https://open.bigmodel.cn/api/paas/v4",
     "model": "glm-4v-flash",
     "api_key": "你申请到的 Key"
   }
   ```

   `provider` 也可以写 `dashscope`（通义）/ `siliconflow` / `openai` / `ollama`（本地），
   这几家只填 `provider` 和 `api_key` 就行，地址和模型名会自动补上。
3. 存盘 → 退出（右键挂件 →「我先走了（退出）」）→ 重新双击 exe。

> 配置、记忆、语料、日志都在 `%APPDATA%\ScreenPet\`（开始菜单地址栏粘
> `%APPDATA%\ScreenPet` 就能打开）。删掉 exe 不会丢，重装还认得你。
> 想让它把东西放在别处（U 盘便携版）：设一个环境变量 `PET_HOME=D:\ScreenPet` 再启动。

第一次启动时它还会**给自己装一点常识**：随包带的一份 `knowledge.example.json`（上网补课学到
的几条通用知识点 + 一份"这些话头学过了"的账本）会被撒进你自己的目录，撒完落一个
`.knowledge-seed.json` 标记，**只撒一次**。

这份常识里**没有别人的东西**——用户画像、爱好标签、屏幕上看来的台词/接话语料都不会跟着来。
你的记忆从头到尾是你自己攒的：删除 / 重装 / 换台机器，宠物都只认得你。

不想要这份常识：删掉 `memory.json`、`data\study.json` 和那个 `.knowledge-seed.json`
标记就行（标记一删它会以为"还没撒过"，所以**先删数据文件再删标记**才干净；只想让它忘掉
这一切用右键 →「重新认识一下」）。

## 四、它默认会看什么

- 默认看**整块主屏**。想只看一个区域：右键 →「陪你看」→「手动划观看范围…」→ 拖一块（双击 = 整块屏）。
- 想只盯着某个程序（B站 / 抖音 / 游戏）：右键 →「只盯着一个程序」→ 挑一个窗口。
- 画面不动的时候它不会重复截图，也不会重复问模型（省钱）。

## 五、全部用鼠标（没有热键）

以前这里有六个热键，**现在整套撤掉了**——右键菜单里全都点得到：

| 想干什么 | 在哪儿点 |
| --- | --- |
| 先歇会儿（不看屏幕了）/ 接着看 | 右键 →「陪你看」第一项 |
| 划观看范围 | 右键 →「陪你看」→「手动划观看范围…」（拖一块 = 只看这块，双击 / F = 整块屏） |
| 打字跟它聊 | 右键 →「跟我说说话」→「打字跟我唠…」（只开不收） |
| 说话（用系统自带识别，离线） | 右键 →「跟我说说话」→「说一句（语音）」，或面板上的「麦克风」 |
| 逗它玩（随机演一个动作） | **左键点它一下**（不用进菜单） |
| 把我钉在这儿（鼠标点不到它）/ 松开 | 右键 →「我自己的事」第一项（锁着时鼠标压上去会临时解锁，随时点得回来） |

鼠标停在它身上 0.9 秒它会跟你挥手；双击它是暂停 / 继续看；把它拖起来再放下，落地蹦一下。

## 六、隐身学习（收进托盘时自己上网补课）

把它收进托盘 = "这会儿不用你"，于是它**不再拍你的屏幕**，改成自己上网学点东西。
这条**默认开着**——收进托盘就自己补课，**没有开关**（右键菜单里那个勾选项已经撤了）。
不想让它花这份联网的接口钱，就在配置里关掉：

```json
"study": { "enabled": false, "model": "glm-4-flash" }
```

开着的时候建议把补课用的模型单独指到一个**文本模型**上（比视觉模型准、也便宜；
上面那行里的 `model` 就是干这个的，删掉 `"enabled": false` 就恢复默认的"自己学"）。

它学到的东西会分别进 `data/chat_style.json`（说话方式）和 `memory.json`（知识）。

## 七、出问题了去哪儿看

1. **日志**：`%APPDATA%\ScreenPet\run.out`（每行都带 `[study]` `[watch]` `[vc]` 这种前缀，
   一看就知道哪一步不对）。
2. **自检**：在命令行里跑 `ScreenPet.exe --selftest`（不用装 Python，自检逻辑打包在里面了）
   ——会截一张屏、跑一次 OCR、试调一次模型。它是**无控制台**的程序，看不到黑框输出，
   结果照旧写进 `%APPDATA%\ScreenPet\run.out`；跑完去那个文件末尾看。
3. **配置没生效？** 多半是改错了文件：打包版读的是 `%APPDATA%\ScreenPet\config.json`，
   **不是** exe 旁边的那个。日志第一行会写明"写：… 读：…"，照它核对。

## 八、卸载

- 绿色版：删掉整个文件夹 + `%APPDATA%\ScreenPet`（后者可选：不删就留着记忆）。
- 安装版：设置 → 应用 → 卸载 screen-pet；`%APPDATA%\ScreenPet` 同样保留，想清干净就手动删。

卸载**不会**自动删你的记忆和语料——重装之后它还认得你。
